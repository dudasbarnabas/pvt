# PVT

[Download releases](https://github.com/dudasbarnabas/pvt/releases)

You need internet connection.

1. Extract .zip
2. Paste .env to _internal/
3. Start Launcher.exe
4. Wait for version check
5. Start the experiment with "start"
6. Edit settings on popup or leave the defaults
7. Do the experiment.
8. After the window closes the data is saved to data/
